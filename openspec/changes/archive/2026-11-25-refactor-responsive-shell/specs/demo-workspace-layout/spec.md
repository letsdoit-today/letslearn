# Spec Delta

## MODIFIED Requirements

### Requirement: 画布、控制区与 KPI 条同屏共存

在宽屏桌面视口（宽度 ≥ 1280px）下，系统 SHALL 保证实验画布、控制区与 KPI 读数条三者同时完整落在可视区域内，无需滚动即可看到参数变化与物理响应的对应关系。

#### Scenario: 1366×768 视口

- **WHEN** 用户在 1366×768 的视口下打开任一演示页面并滚动到工作台顶部
- **THEN** 实验画布、控制区与 KPI 条三者的底边均不超过可视区域下边界

#### Scenario: 1920×1080 视口

- **WHEN** 用户在 1920×1080 的视口下打开任一演示页面并滚动到工作台顶部
- **THEN** 实验画布、控制区与 KPI 条三者的底边均不超过可视区域下边界，且工作台下方仍有余量

#### Scenario: 左侧导航折叠

- **WHEN** 用户折叠左侧导航使内容区变宽、画布随宽度等比增高
- **THEN** 系统仍保证画布与 KPI 条的合计高度不超过可视区域高度

#### Scenario: 中等桌面视口降级

- **WHEN** 用户在 1024–1279px 的视口下打开任一演示页面并滚动到工作台顶部
- **THEN** 侧栏回落为画布列下方的纵向排列，画布与 KPI 条的底边不超过可视区域下边界，且画布宽度不低于同一视口下纵向排列前的宽度

#### Scenario: 断点切换时画布宽度不倒退

- **WHEN** 视口宽度跨过 1280px 断点
- **THEN** 侧栏由画布下方切换为画布右侧，画布绘制宽度保持不小于切换前宽度的一半
