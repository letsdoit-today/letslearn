# Design

## Context

- 两个实验的受力箭头都用「力值(N) × 固定像素比例」直接映射为箭头像素长度，未检查箭头端点是否落在 `viewBox` 内。
- `SimulationCanvas` 的 SVG 使用 `viewBox` + 默认 `preserveAspectRatio="xMidYMid meet"`，落在 `viewBox` 外的内容会被 SVG 自身裁剪（与 CSS `overflow` 无关）。
- 关键约束：`SimulationCanvas` 的 SVG 为 `w-full h-auto`，内容缩放比只由「容器宽度 / viewBox 宽」决定，与 viewBox 高度无关；因此「加高 viewBox」只会增加底部留白，不会缩小内容或改变箭头相对比例。
- 斜面摩擦实验：`viewBox="0 0 700 400"`，重力箭头长约 137px（G=98N × scale 1.4），物块中心 y≈322，尖端 y≈459 超出底部 y=400。
- 球体落入液体实验：`height` 同时用作 viewBox 高度与物理底面，球体停在 `y = height - 半径`；`arrowScale=2` 时重力箭头长约 220px，沉底后尖端 y≈706 远超 `height=500`。

## Goals / Non-Goals

**Goals:**

- 两个实验中所有受力箭头在任意参数、任意动画时刻都完整落在 `viewBox` 内。
- 保持箭头之间的相对长度比例，不破坏力的大小对比。

**Non-Goals:**

- 不改变物理模型与受力数值。
- 不实现「箭头随剩余空间动态限长」的自适应缩放（用户明确不倾向该方案）。
- 不处理透镜类实验（对象/像箭头，性质不同，非受力箭头）。

## Decisions

### Decision 1：斜面摩擦实验——加高 viewBox（700×400 → 700×500）

- 重力箭头长约 137px，物块中心 y≈322，尖端 y≈459；加高到 500 后尖端与标签均在界内，且为标签预留约 40px 余量。
- 仅改 `viewBox` 高度，不动 `scale`、几何与物理计算；箭头相对比例保持不变。
- 备选「上移支点/地面」——否决：80° 时木板顶端已接近 y=5，上移会把木板顶端顶出画布顶部。
- 备选「自适应限长」——否决：用户担心比例失真、无法区分箭头差距。

### Decision 2：球体落入液体实验——降低 arrowScale + 解耦 viewBox 与物理底面

- 关键发现：该实验中 `height` 同时是 viewBox 高度与物理底面，球体会停在 `y = height - 半径`；若只加高 `height`，球会跟着落到更低处，向下的重力箭头仍会超出新底面。因此必须把「viewBox 高度」与「物理底面」解耦。
- 具体做法：`arrowScale` 由 2 降为 1.0（重力箭头 220px → 110px，各箭头按同一因子缩放）；引入底部边距常量 `bottomMargin = 120`，`viewBox = 0 0 ${width} ${height + bottomMargin}`（即 800×620），物理底面保持在 `height = 500`，从而在底面下方预留约 120px 供向下箭头使用。验证：沉底时重力箭头尖端 y≈596 < 620。
- 备选「仅加高 viewBox」——否决（height 同时是物理底面，见上）。
- 备选「球在底部时把重力箭头改画为向上/侧向」——否决：破坏「箭头从物体中心出发」的既有约定，且会误导受力方向。

### Decision 3：不改箭头相对比例

- `FallingBall` 的 `arrowScale` 是全局因子，G/Fb/Fd/N 一起缩放，相对大小差距保持不变（如 G≈110px vs Fb≈14px），满足用户「保持箭头差距可区分」的诉求。

## Risks / Trade-offs

- [落体实验画布变高] → 卡片纵向变高（宽高比约 1.6 → 1.29），内容本身不缩小但占更多纵向空间；可接受，必要时微调 `bottomMargin`。
- [斜面摩擦实验底部留白] → 斜面下方多出空白；属预期，为竖直箭头留空间。
- [取值依赖经验] → `arrowScale=1.0`、`bottomMargin=120` 为经验值；若后续参数（质量、密度等）范围扩大可能需再调整。缓解：以命名常量集中声明，便于集中调节。
