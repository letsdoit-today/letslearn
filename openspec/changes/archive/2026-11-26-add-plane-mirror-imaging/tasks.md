# Tasks

## 1. 几何内核

- [x] 1.1 在 `src/lib/physics/planeMirror.ts` 定义输入类型（镜面倾角、物体位置与高度、入射点参数）与结果类型（像位置、像高、物距、像距、入射角、反射角、光路端点），并导出默认参数，验证 `tsc` 通过且被 demo 引用时无隐式 any
- [x] 1.2 实现镜像变换 `reflectPoint(P, A, n)`，按 `P' = P - 2·((P - A)·n)·n` 计算任意倾角下的像点，验证镜面竖直时像点与物点 x 坐标关于镜面对称、镜面倾斜 30° 与 45° 时像距仍等于物距
- [x] 1.3 实现物距与像距的带符号计算及 cm 换算（1 cm = 20 px），验证读数恒相等且落在 5–20 cm 的合理区间
- [x] 1.4 实现两条入射光线的反射求解：给定入射点，求入射角与反射光线方向，验证反射角等于入射角、入射与反射光线分居法线两侧
- [x] 1.5 实现反射光线的反向延长线求交，验证两条延长线的交点与 1.2 求得的像点重合（误差小于 0.5 px）
- [x] 1.6 实现入射点随物体位置的自适应取值，验证物体在拖拽范围内任意位置时两条光线端点均落在画布内、入射点始终位于镜面可视段
