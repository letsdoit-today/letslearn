# Design

## Context

`/concave-lens/` 与 `/convex-lens/` 共用同一套演示骨架（`DemoPage` + `useSVGScene` + `ParamSlider` + `KpiBar`），画布 viewBox 为 `800×500`，`centerX=400`、`centerY=250`、`f=100`、`lensHeight=200`、物高 60。动机见 proposal.md - Why。

当前页面的物理计算已经正确：`calculateThinLens(u, -CONFIG.f)` 在 `f<0` 时返回 `v`（负值）与 `m`（正值、恒小于 1），`typeKey` 固定为 `image-type-upright-reduced-virtual`。因此本次不需要改动物理层，问题集中在几何标注与呈现层。

`/lens-imaging-rules/` 的对照表已含一行凹透镜对比与「凹透镜对任何物距都只成正立、缩小的虚像」口诀，本次不重复该表格。

## Goals / Non-Goals

**Goals:**
- 修正三处会误导学生的几何标注：二倍焦点、虚焦点表示、负值像距。
- 补齐第三条特殊光线，使三条光线反向延长线共点这一作图结论在画面上自洽。
- 补齐初中凹透镜的两个必考点：虚焦点与不可用光屏承接。

**Non-Goals:**
- 不引入焦距可调滑块（`f` 保持 100）。
- 不引入可拖光屏或清晰度判定。
- 不引入物距区段高亮（凹透镜不存在 `u>2f` / `f<u<2f` 分界）。
- 不改动 `src/lib/physics/lens.ts` 的计算逻辑，也不改动 `convex-lens-imaging` 与 `plane-mirror-imaging` 的行为。

## Decisions

### 1. 虚焦点用虚线空心圆，彻底移除二倍焦点

凸透镜的 `2F` 承担「放大/缩小分界」的判定作用；凹透镜放大率恒小于 1，`2F` 无任何判定意义，保留实心点会诱导学生去找并不存在的分界。同理，凹透镜的 F 是反向延长线的交点（虚焦点），画成与凸透镜一致的实心圆点会让「光线真的交于此」与「延长线交于此」无法区分。

实现上把原 `points` 数组的四个实心点改为两个：`F` 与 `F′`，各自 `circle(8)` 但 `fill('none')` + `stroke({ width: 1.5, dasharray: '2,2' })`，文字标注改为「虚焦点 F」「虚焦点 F′」，位置仍为 `cy + 20`。

替代方案：保留 `2F` 但改灰、改细。否决理由——只要它还叫 `2F`，学生就会去用；正确的做法是不给错误锚点。

### 2. 第三条特殊光线常显，不设开关

补一条「射向像侧虚焦点 F′、出射后平行主光轴」的光线。按当前参数验算几何自洽性：

```
物顶 (100,190)  瞄准 F'(500,250)
入射斜率 = (250-190)/(500-100) = 0.15
到透镜 x=400 处：y = 190 + 0.15*300 = 235
出射水平：(400,235) --> (800,235)
反向延长水平向左 --> (325,235)
像顶坐标：imgX = 400 + v = 400 - 75 = 325，imgTopY = 250 - 60*0.25 = 235   ✓ 共点
```

这条光线的反向延长线是水平线，比另两条更容易看出「三条延长线交于像点」，对作图题价值最高。因此设为常显，不提供开关，避免侧栏控件继续膨胀（`README.md` 已约定侧栏内容高度不得超过视口）。

替代方案：做成可切换的「第三条光线」开关。否决理由——它是最直观的一条，默认关掉反而降低教学效果；且新增开关会占用侧栏高度预算。

### 3. 反向延长线延长到虚焦点

现有 `virtualFocus` 路径为 `M(cx, objTopY) L(imgX, imgTopY)`，止于像点，导致「平行光折射后发散、反向延长线过虚焦点」这句话在画面上看不出来。延长到 `(cx - f, cy)` 即可：

```
折射斜率 = (objTopY - cy)/f = (190-250)/100 = -0.6
x=325 处：y = 190 - 0.6*(325-400) = 235   ✓ 过像顶
x=300 处：y = 190 - 0.6*(300-400) = 250   ✓ 落在 F(300,250)
```

同一段虚线因此同时满足「过像点」与「过虚焦点」，无需新增图元。

### 4. 像距取绝对值 + 同侧表述

物理层的 `v` 保持负值（符号约定属于内部实现），呈现层统一转换：

- `v` 卡显示 `Math.abs(v)`；
- 新增「像的位置」卡显示「同侧」，hint 写「光屏不可承接」。

不采用「把 `v` 改成正值」的做法，因为 `lens.ts` 的负值语义是凸/凹透镜共用公式的一部分，改动会波及 `ConvexLensSim` 与 `LensImagingRules`。

### 5. KPI 固定 5 卡，与凸透镜页同规格

画布宽度在 1024×768 下约为 636px，每卡 `min-w-[6.5rem]`（104px）+ 8px 间距，5 卡共需 552px，可单行放下；6 卡需 664px 必然折行（该结论已在上一次凸透镜改动中实测确认）。

最终 5 卡：物距 u / 像距 v（绝对值）/ 放大率 m（hint 像高 h′）/ 成像性质 / 像的位置（hint 光屏不可承接）。

### 6. 考点速查放 `extra` 插槽

与 `/convex-lens/` 一致，放在演示区下方而非侧栏，`grid gap-3 sm:grid-cols-2` 两列排布。内容 6 条：发散作用、虚焦点含义、光屏不可承接、近视眼镜、判断透镜类型、物近像大。末尾以链接指向 `/lens-imaging-rules/`，不渲染表格。

### 7. 关键词分工：主词归演示页

`凹透镜成像规律` 原本同时出现在 `concave-lens` 与 `lens-imaging-rules` 的 keywords 中。对照表页关于凹透镜只有一行对比与一句口诀，内容量不足以支撑该主词，继续保留会造成两页互相稀释。改为：`concave-lens` 独占「凹透镜成像规律」及其组合词；`lens-imaging-rules` 移除该词，保留其凸透镜对照表主词。

## Risks / Trade-offs

- **移除 `2F` 后画面参考点变少** → 凹透镜没有「分界」概念，少一个错误锚点优于多一个参照；`F` 与 `F′` 仍保留，足以定位焦距。
- **水平反向延长线可能与主光轴混淆** → 第三条光线的反向延长线画在 `y=235`，与主光轴 `y=250` 相距 15px，且使用 `dasharray` 虚线，视觉上可与实线主光轴区分。
- **「虚焦点 F′」文字与既有 `O` 标签可能拥挤** → 两个焦点分别在 `x=300` 与 `x=500`，间距 200px，`cy+20` 行只有一个标签，不与 `O`（`cx+15`）重叠。
- **KPI 5 卡在更窄视口折行** → 与凸透镜页现状一致，属于既有布局基线，由 `verify:layout` 的侧栏与画布断言兜底。
- **关键词移除后对照表页该词流量下滑** → 该词在对照表页本就不具备内容优势，属预期内的让位；对照表页保留 `凸透镜成像规律` 系列主词。
