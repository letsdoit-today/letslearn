# Design

## Context

现有画布组件 `SimulationCanvas` 是一个 `relative overflow-hidden` 的边框容器，内部 `<svg class="w-full h-auto">` 随容器宽度等比缩放，而图例是 `absolute top-4 right-4` 的固定像素浮层。两套坐标系不一致是遮挡的根因，实测数据见 `proposal.md - Why`。

4 个页面各自手写了一份图例，规格漂移为两套（`p-3 text-sm w-3 h-3` 与 `p-2 text-xs w-2.5 h-2.5`）。`FallingBall` 的图例与侧栏 `DataPanel` 逐字重复同一批彩色数值。

约束：上一轮 `refactor-demo-kpi-layout` 已经把「画布 + 侧栏 + KPI 条」压进一屏预算（1366×768 下最紧的 `PendulumOscillation` 为 636px / 768px），新增的图注行必须留在剩余预算内。

## Goals / Non-Goals

**Goals:**

- 图例脱离浮层体系，在任何视口下不遮挡画布内容
- 收口 4 份重复实现为 1 个共享组件，消除规格漂移
- 用自动化断言固化「浮层面积受限」这一约束，防止回归

**Non-Goals:**

- 不改 `lg` 断点导致的画布塌陷（1024px 下画布 294px 比手机还窄），该问题单独 change 处理
- 不改 `KpiBar`、`DataPanel` 与侧栏结构，不合并「图例 / KPI 染色 / DataPanel 彩色数值」三套颜色语义
- 不把图例画进 SVG 内部随 viewBox 缩放（窄屏下字体会缩到不可读）
- 不在窄屏隐藏图例（手机上图例是唯一清晰的参考信息）

## Decisions

### 图注位置：画布边框之下，作为 `DemoMain` 的子节点

`CanvasLegend` 作为 `<SimulationCanvas>` 的兄弟节点渲染在 `DemoMain` 内，紧随画布之后、`KpiBar` 之前。

- 备选：放进 `SimulationCanvas` 的 `children`（边框内、svg 之下）。视觉上是框内图注，但会让 `SimulationCanvas` 承担「图注容器」职责，且 `overflow-hidden` 下换行条目可能被裁切。
- 备选：加 `legend` prop 到 `SimulationCanvas`。改共享组件签名，且与「画布只负责画」的职责划分相冲突。
- 选兄弟节点的理由：职责单一，`SimulationCanvas` 零改动，图注参与正常文档流换行。

### 图例承载的信息：静态参考，不含逐帧数据

沿用上一轮把 `x_total / τ / v∞` 下沉到 `reference` 的判断：图例只描述「颜色 → 物理量」映射，逐帧数值一律留在 `KPI` 条。

`PendulumOscillation` 的「箭头长度以 mg 归一化」属于静态说明，随图例移入图注并做弱化处理（`text-[11px] text-muted-foreground`）。

### 标签文案缩短

浮层时代图例宽度主要由散文式标签撑开（`力臂 L′（支点到作用线的垂距）` 单行即 253px）。改为图注后宽度不再有硬约束，但保留精简文案：括号内的解释属于讲解区内容，图注只保留符号与量名。

### 画布内保留的浮层：仅短文本芯片

时间芯片、平衡状态徽章、运动状态徽章继续留在画布内（它们是逐帧状态，需要与画面同时可见），但只允许短文本，并以 25% 面积上限做自动校验。

### 校验脚本扩展

`scripts/verify-layout.mjs` 视口矩阵补入 `1024×768`（暴露 `lg` 断点切换后的窄画布），新增断言：遍历 `[data-demo-canvas]` 的绝对定位子元素，`宽 × 高 / 画布宽 × 画布高 ≤ 0.25`。

- 阈值取 25% 而非更严：1366×768 下现存芯片约 2%–7%，1024px 下约 6%–7%，25% 留出足够余量又不至于放过图例级别的浮层（原始图例在 1024px 下为 86%×28% ≈ 24%——阈值须低于该值才具备捕获能力）。
- 备选：只断言宽度占比。高度占比同样会退化（768px 下图例高 48%），单维度不足。

## Risks / Trade-offs

- [图注行占用垂直空间，可能挤出同屏预算] → 图注单行约 26px + 12px 间距；最紧的 `PendulumOscillation` 636px → 674px，仍低于 768px。`verify:layout` 的同屏断言会捕获越界。
- [25% 面积阈值对未来的小型浮层偏松] → 属于有意取舍：阈值须低于图例级别（约 24%–24%）才有捕获力，更严会误伤多行状态徽章。若后续出现新浮层形态，再单独收紧。
- [窄屏下图注换行导致页面变长] → 图注在图下而非画布内，变长只影响页面滚动长度，不影响画布可视面积，与「同屏看画布 + 控制 + KPI」的目标不冲突。
- [图例与 KPI 染色语义仍并存] → 本次不合并，属于另一个决策（颜色语义统一），在非目标中明确排除，避免 scope 蔓延。
