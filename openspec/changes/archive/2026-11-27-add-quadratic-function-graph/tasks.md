## 1. 求解内核

- [x] 1.1 在 `src/lib/math/quadratic.ts` 定义常量与类型：`X_MIN = -5`、`X_MAX = 5`、`Y_MIN = -10`、`Y_MAX = 10`、`A_MIN = -2`、`A_MAX = 2`、`A_STEP = 0.5`、`B_MIN = -3`、`B_MAX = 3`、`C_MIN = -5`、`C_MAX = 5`，以及 `QuadraticInput`（`a`、`b`、`c`）与 `QuadraticSolution`（`vertex`、`axisX`、`discriminant`、`roots`、`yIntercept`、`opensUp`）；验证方式：`npx tsc --noEmit` 通过，被 demo 引用时无隐式 any
- [x] 1.2 实现 `solveQuadratic(input)`：返回顶点 `h = -b/(2a)`、`k = c - b²/(4a)`、对称轴 `x = h`、判别式 `Δ = b² - 4ac`、与 `y` 轴交点 `(0, c)`、`opensUp = a > 0`；验证方式：断言 `(1,0,0)` 顶点为 `(0,0)`、`(1,-2,1)` 顶点为 `(1,0)`、`(1,0,-4)` 顶点为 `(0,-4)`、`(1,0,3)` 的 `Δ = -12`
- [x] 1.3 实现根求解 `rootsOf(input)`：`Δ > 0` 返回两个实根 `(-b ± √Δ)/(2a)`、`Δ = 0` 返回单元素数组、`Δ < 0` 返回空数组；验证方式：断言 `(1,0,-4)` 返回 `[-2, 2]`、`(1,-2,1)` 返回 `[1]`、`(1,0,3)` 返回 `[]`
- [x] 1.4 实现 `evaluate(input, x)`：返回 `a * x² + b * x + c`；验证方式：断言 `evaluate((1,0,0), 0) = 0`、`evaluate((1,-2,1), 1) = 0`、`evaluate((-1,0,0), 2) = -4`
- [x] 1.5 实现 `snapA(raw, prev)`：`raw` 非 0 时返回 `raw`，为 0 时按 `raw` 与 `prev` 的大小关系取方向返回 `±0.5`；验证方式：断言 `snapA(0, -0.5) = 0.5`、`snapA(0, 0.5) = -0.5`、`snapA(1.5, 1) = 1.5`
- [x] 1.6 实现 `curvePoints(input, samples)`：在 `[X_MIN, X_MAX]` 上均匀取 161 个点返回 `{ x, y }[]`；验证方式：断言返回长度为 161、首点 `x = -5`、末点 `x = 5`、中点 `x = 0` 且其 `y = c`
- [x] 1.7 实现 `PRESETS` 常量：标准型 `(1,0,0)`、开口向下 `(-1,0,0)`、双根 `(1,0,-4)`、顶点在轴上 `(1,-2,1)`、无实根 `(1,0,3)`；验证方式：断言五个预设的 `Δ` 分别为 `0`、`0`、`16`、`0`、`-12`，且三类判别式符号各至少出现一次
- [x] 1.8 在 `tmp/` 下用一次性脚本跑通 1.2–1.7 的全部断言，并额外验证「参数区间内 `|h| ≤ 3`、`|k| ≤ 9.5`」；验证方式：脚本全部断言通过，输出中可见两个极值，脚本在任务末尾删除
