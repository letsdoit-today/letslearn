# Proposal

## Why

`/convex-lens/` 目前演示的是「薄透镜成像公式」，而初中物理的考试重心是「光具座上的实验操作」。对照 12 个高频考点，有 7 个完全空白（光屏能否承接实像、焦距可调、遮挡透镜、三心共轴、找不到像的原因、测焦距、u-v 图像），且这 7 项恰好集中在几乎必考的「实验探究题」。同时该页承载 Bing 建议中 566 展现、趋势上升的「凸透镜成像实验」关键词，当前页面内容与该搜索意图不匹配。

## What Changes

- 在现有光路图画布上叠加可拖动的光屏，拖动到像位置时提示「像清晰」，否则提示「模糊」，把「实像可被光屏承接、虚像不能」从文字描述变成可操作事实。
- 焦距 `f` 由常量改为可调参数，用于演示「物距不变换用焦距更小的透镜，光屏需靠近透镜、像变小」这一经典实验问法。
- 补上第三条特殊光线（过焦点入射、出射平行主光轴），使三条特殊光线齐全，支撑作图题。
- 移除自动演示中主动跳过 `u = f` 的逻辑，允许停留在 `u = f` 并显式呈现「出射光平行、不成像」。
- 新增「遮住透镜上半部分」开关：像仍完整，只是变暗。
- KPI 由 4 项扩展为 6 项，补充像的位置（同侧/异侧）、能否用光屏承接、像高 `h' = |m|·h`。
- 画布上标注 `u > 2f` / `f < u < 2f` / `u < f` 三个区段，使滑块位置与「第几种成像情况」视觉对应。
- 在页面正文补充「实验考点速查」：三心共轴、找不到像的三种原因、两种测焦距方法、蜡烛变短导致像上移、遮住一半像变暗。
- 与 `/lens-imaging-rules/` 划清分工：该页继续承担信息型查询（五种情况对照表、口诀、凹透镜对比），本页只承担操作型查询，不复制对照表内容。
- 更新 `demos.json` 中 `convex-lens` 的 description 与 keywords，补充「光具座」「光屏承接」「焦距可调」等实验相关表述。

## Capabilities

### New Capabilities

- `convex-lens-imaging`: 凸透镜成像交互演示的行为约定，涵盖物距/焦距调节、光屏承接判定、三条特殊光线、遮挡实验与考点辅助内容。

### Modified Capabilities

（无。现有 spec 均不覆盖该页面，`demo-workspace-layout` 与 `demo-canvas-legend` 的既有要求不被改变。）

## Impact

- 代码：`src/demos/ConvexLensSim.tsx`（主要改动）、`src/lib/demos.json`（元数据）、`src/components/demo/DemoPage.tsx`（若 `extra` 插槽需承载新内容则复用，不新增结构）。
- 校验：`scripts/verify-layout.mjs` 需补充「侧栏内容真实高度」度量，避免仅依赖被 flex 拉伸的框高；侧栏新增控件高度需控制在约 110px 以内，以适配 1024 视口堆叠布局。
- 产物：画布变化后需重新执行 `npm run og:image` 生成 `public/og-convex-lens.jpg`。
- 文档：`README.md` 补充光屏 overlay 的交互约定；`ROADMAP.md` 更新该条目说明。
- 依赖：无新增第三方依赖，沿用 `@svgdotjs/svg.js` 与既有 pointer 事件模式。
