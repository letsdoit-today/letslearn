# Proposal

## Why

`/friction-inclined-plane/` 目前只能「看」：倾角由自动演示从 0° 抬到 80°，用户无法给定倾角去判断物体是否下滑；临界角 `tanθc = μ` 只写在讲解卡片里，画布与 KPI 都看不到它；讲解承诺把重力分解为 `Gx` 与 `Gy`，画布却只画了 `Gx`。同时 `demos.json` 的 description 声称「可调节斜面倾角、物体质量与摩擦因数」，而实际只有 `μ` 一个滑块，元数据与实现不符。对照初中「探究影响滑动摩擦力大小的因素」与高中「斜面动力学」的高频考点，临界角、质量无关性、摩擦力的静/动跃变、摩擦力方向判断均无法在该页被操作或观察。

## What Changes

- 倾角 `θ` 由自动演示专用改为可调参数：新增 0–80° 滑块，自动演示继续存在，滑块可随时接管。
- 新增物体质量滑块（1–20 kg），用于演示「临界角与质量无关」这一对照实验。
- 摩擦系数滑块下限由 `0.1` 放宽到 `0`，覆盖光滑斜面极限。
- 画布补画重力垂直分力 `Gy`，兑现讲解卡片承诺的 `Gx` / `Gy` 正交分解。
- 画布新增「临界斜面」幽灵板：在 `θc = arctan μ` 角度位置绘制半透明虚线板，当前斜面越过它时物体开始下滑，使临界条件成为可见事实。
- 状态机由「静止 / 滑动」两态扩展为「静止 / 临界 / 下滑 / 上滑」四态，并在画布角标中以颜色与文案区分。
- 新增「初速度上滑」模式：方块以给定初速度冲上斜面，摩擦力反向，用于演示摩擦力方向由相对运动趋势决定。
- KPI 由 4 项扩展为 6 项：`θ`、`θc`、`Gx`、`f_max`、`f`、运动状态（含下滑加速度提示）。
- 侧栏的实时读数面板（`G`、`N`）移出侧栏，改为按实时性分层的呈现方式，修复对 `demo-workspace-layout` 「侧栏 MUST NOT 包含实时读数」的违反。
- 工作台下方新增「实验考点速查」内容区，覆盖质量无关性、临界角计算、静摩擦不等于 `μN`、摩擦力方向判断、斜面越陡越易下滑的定量解释，并附 `μ → θc` 对照表。
- 重写 `demos.json` 中该条目的 description 与 keywords，使其与真实能力一致。
- 自动演示的动画循环改为仅在模拟进行时驱动，消除页面空闲时每帧空转，并按时间步长而非固定帧步长推进速度。

## Capabilities

### New Capabilities

- `friction-inclined-plane`: 斜面摩擦交互演示的行为约定，涵盖倾角与质量调节、临界角可视化、静摩擦与滑动摩擦的跃变、上滑时摩擦力反向、受力分解绘图与考点辅助内容。

### Modified Capabilities

（无。`demo-workspace-layout` 的既有要求不被改变，本次改动只是让该页面重新满足它们。）

## Impact

- 代码：`src/demos/FrictionInclinedPlane.tsx`（主要改动）、`src/lib/physics/inclinedPlane.ts`（补充临界角与加速度派生量）、`src/lib/demos.json`（元数据）。
- 校验：`scripts/verify-layout.mjs` 逐路由断言同屏与溢出，侧栏移除实时读数后需重新确认通过；`npm run build:prerender` 需通过。
- 产物：画布变化后需重新执行 `npm run og:image` 生成 `public/og-friction-inclined-plane.jpg`。
- 文档：`README.md` 与 `ROADMAP.md` 更新该条目说明。
- 依赖：无新增第三方依赖，沿用 `@svgdotjs/svg.js` 与既有 pointer 事件模式。
